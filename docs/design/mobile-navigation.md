# 手机导航与搜索

## 2026-11-04 用户要求

- 手机是纯快递工具，移除内置对话、模型配置、语音、记忆、AI 进度/ETA、商品 AI 短名和日报；服务器只提供确定的查询/操作接口给外部工具，不在软件内接入模型。
- 固定底部栏，左「快递」、右「身份码」，切换留在同一页面壳内。快递页顶部搜索，输入运单号自动识别承运商，在搜索结果处直接添加；不再独立弹出添加页。
- 页面不出现验收状态、材料续期策略、项目模块说明等开发信息。身份码页只显示码和刷新操作；导入与维护用 API。
- GitHub、支持和更新统一指向 AlexbeatsZ/ExpressAssistant。保留开源许可中的上游署名。

## 视觉和交互

2026-11-06 用户追加要求：手机只保留莫奈取色，删除主题入口、温暖纸感与自定义配置。配色使用 Material 系统动态取色，昼夜跟随系统；字体为系统无衬线，码与单号保留等宽，条形码保留白底。升级时仅清理旧主题偏好，不重置其他数据；详见 `docs/THEME.md`。

```
快递                         日历 清单 设置
[ 搜索商品、快递公司或运单号            × ]
[ 承运商 · 运单号                  添加 ]  ← 仅识别到新运单号时出现
快递列表 / 搜索结果 / 空状态
─────────────────────────────────────
          快递            身份码
```

身份码使用同一工具栏和底部栏；内容只放白底条形码、码文本、刷新按钮、必要的操作错误。未出码给「暂不可用」和重试动作，不解释材料实现。底部栏避开系统手势区；键盘打开时保持搜索可用。

识别使用本地运单格式初筛与已有承运商识别接口，输入停顿后查询。只在点击「添加」或提交键盘搜索时保存新件，避免输入未完成时创建多个包裹。相同运单号不重复添加；命中已完成记录时可直接打开。

普通关键字过滤商品名、单号、公司、取件码；搜索包含已完成和异常记录。空查询恢复当前快递分区。手动件有独立 manual 来源，跨渠道同步保留，详情走通用查件接口。

维护入口：MainActivity 接受 query 预填搜索、mailNo 打开已有记录、identity_code 打开身份 tab，供已授权 ADB 与小组件导航，不另装测试组件，也不把私有 DetailActivity 改成导出。输入预填仍走同一搜索监听和承运商识别逻辑。
